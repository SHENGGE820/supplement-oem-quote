# 保健代工線上詢價

B2B 保健食品代工的客戶自助詢價頁：客戶自己選劑型、配方、包裝與數量，馬上看到參考價格區間與建議訂購量；送出後，完整規格會以 Email 寄給業務。單一 HTML 檔，不需安裝。

**線上試用：** https://shengge820.github.io/supplement-oem-quote/

設計相關文件：[DESIGN.md](DESIGN.md)（設計語言）、[DESIGN-REVIEW.md](DESIGN-REVIEW.md)（設計審查紀錄）

## 工作情境

| 項目 | 說明 |
|---|---|
| 工作情境 | B2B 保健代工線上詢價：客戶自助選規格、取得參考報價，詢價自動寄給業務 |
| 原本作業方式／痛點 | 客戶詢價時規格常不完整，業務要來回確認劑型、配方與包材，再人工比對原料、代工工時與包裝印刷階梯單價，整理一份報價超過 40 分鐘 |
| 使用的 AI／自動化工具 | ChatGPT (Data Analysis) 整理計價邏輯、Excel 自動化邏輯，轉成網頁詢價單＋Email 自動通知 |
| 本次完成的功能 | 客戶線上選擇劑型、配方、盒型、紙材、特殊工藝與數量，即時看到參考價格區間與建議訂購量；送出後業務收到含完整規格的詢價信 |
| 導入前後改善 | 客戶約 3 分鐘取得參考報價，不必等業務整理；業務收到的詢價規格一次到位，減少來回確認 |

## 功能

**客戶端**
- 4 種常見產品範本（葉黃素膠囊、膠原蛋白粉包、魚油軟膠囊禮盒、B 群錠），一鍵帶入再調整
- 6 種劑型、主要成分與劑量、每盒入數、內包裝、外盒、紙材、印刷、表面處理、特殊工藝、標籤、品質檢驗
- 同時比較 3 種訂購數量，顯示每盒與每粒參考價格區間、含稅總額，並以「建議」印章標出建議訂購量
- 階梯價格線：畫出每盒單價隨訂購量下降的曲線，以及數量級距造成的價格跳降
- 自動提醒劑量超過膠囊容量、數量低於最小生產量、成分與劑型不搭等問題
- 數量與聯絡資料即時驗證；未送出的內容會自動保存在瀏覽器
- 送出後顯示詢價編號與摘要，可列印或複製

**業務端**
- 收到主旨為「【線上詢價】公司｜產品｜編號」的 Email，內容包含聯絡資料、完整規格、三個數量的參考價與系統試算價、客戶其他需求
- 直接回覆該信即可回覆客戶（回覆地址設為客戶 Email）

## 設定寄信（Web3Forms）

1. 到 https://web3forms.com ，輸入業務要收信的 Email，取得 Access Key（不需設定密碼）。
2. 打開 `index.html`，找到 `CONFIG`，把金鑰填進 `web3formsKey: ''` 的引號中。
3. 推上 GitHub 後，到網頁版填一筆測試詢價，確認信箱收得到。

金鑰留空時為示範模式：流程完整，送出後會顯示「這次沒有真的寄出」，並列出業務會收到的 Email 內容。

## 計價邏輯（內部，客戶只看得到區間）

```
每盒成本 = 原料 + 代工製造 + 內包材 + 外盒印刷 + 標籤與包裝工資 + 一次性費用 ÷ 訂購盒數
每盒試算價 = 每盒成本 ÷ (1 − 25% 毛利)
客戶看到的參考區間 = 試算價 ±7%
建議訂購量 = 再加一級數量時，每盒若省不到 10% 就停在這一級
```

## 注意

- 資料庫內所有單價皆為課堂示範用估價，並非實際市場行情。
- 目前計價邏輯寫在網頁裡，懂技術的人可以從原始碼看到單價與毛利設定。正式上線應把計價移到後端，網頁只拿回價格區間。
