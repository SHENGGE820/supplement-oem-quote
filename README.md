## 功能

**報價試算**
- 6 種劑型：錠劑、硬膠囊、軟膠囊、粉包、液態飲、果凍條
- 配方可自由增減原料，自動帶入單價，並檢查每粒填充量是否超過劑型上限
- 外盒：盒型、尺寸、紙材、印刷色數、表面處理、特殊工藝（燙金、燙銀、局部 UV、打凸、開窗）
- 同時試算 3 種訂購數量，顯示每盒／每粒單價、含稅總額、毛利與成本組成圖
- 自動標出建議主推方案，並提示低於最小批量、容量超標等問題

**報價單草稿**
- 正式 B2B 報價單格式：單號、有效期限、產品規格、三方案價格表、交易條件、回簽欄
- 內部業務溝通重點：主推理由、成本結構、降本替代方案試算、翻單價、交期與法規提醒
- 一鍵複製報價摘要（LINE／Email）

**原料與包材資料庫**
- 25 項原料單價可直接修改，報價即時重算
- 代工費率、盒型、紙材、印刷、工藝、標籤的階梯單價與檢驗費一覽

## 計價邏輯

```
每盒成本 = 原料 + 代工製造 + 內包材 + 外盒印刷 + 標籤與包裝工資 + 一次性費用 ÷ 訂購盒數
每盒報價 = 每盒成本 ÷ (1 − 目標毛利率)
```

- 原料：每單位劑量（mg）× 原料單價（元／kg），錠劑與膠囊不足重量時自動以賦形劑補足，並計入製程損耗率
- 代工費與印刷費依數量套用階梯係數，量越大單價越低
- 一次性費用：開機清線、刀模、印刷版、特殊工藝版、標籤版、品質檢驗

## 注意

資料庫內所有單價皆為課堂示範用估價，並非實際市場行情。
