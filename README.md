## 功能

**報價試算**
- 6 種劑型：錠劑、硬膠囊、軟膠囊、粉包、液態飲、果凍條
- 配方可自由增減原料，自動帶入單價，並檢查每粒填充量是否超過劑型上限
- 外盒：盒型、尺寸、紙材、印刷色數、表面處理、特殊工藝（燙金、燙銀、局部 UV、打凸、開窗）
- 同時試算 3 種訂購數量，以比較表列出各項成本、每盒／每粒單價、含稅總額、毛利與翻單價
- 階梯價格線：畫出每盒單價隨訂購量下降的曲線，以及印刷、代工數量級距造成的價格跳降
- 自動蓋上「建議」印章標出建議方案並說明理由，同時提示低於最小批量、容量超標等問題
- 數量欄位即時驗證；刪除原料可復原

**報價單**
- 報價方式可選「攤提入單價」或「開發費用另列」（另列時附開發費用明細與翻單是否免收）
- 可編輯單號、日期、有效天數、付款條件、交貨地點、備註，以及雙方公司資料（統編、地址、電話、Email）
- 依公司名稱自動產生報價專用章；A4 列印版面，可直接存成 PDF
- 一鍵複製報價摘要（LINE／Email）

**業務溝通重點（內部）**
- 依價格策略、成本結構、降本方案、交期與風險、法規提醒分組
- 降本方案會實際重算替代規格（例如拿掉燙金、改用卡盒）每盒能省多少

**原料與包材資料庫**
- 25 項原料單價可直接修改，報價即時重算
- 代工費率、盒型、紙材、印刷、工藝、標籤的階梯單價與檢驗費一覽

## 計價邏輯

```
每盒成本 = 原料 + 代工製造 + 內包材 + 外盒印刷 + 標籤與包裝工資 + 一次性費用 ÷ 訂購盒數
每盒報價 = 每盒成本 ÷ (1 − 目標毛利率)
```

- 原料：每單位劑量（mg）× 原料單價（元／kg），錠劑與膠囊不足重量時自動以賦形劑補足，並計入製程損耗率
- 代工費與印刷費依數量套用階梯係數，量越大單價越低
- 一次性費用：開機清線、刀模、印刷版、特殊工藝版、標籤版、品質檢驗

## 注意

資料庫內所有單價皆為課堂示範用估價，並非實際市場行情。
